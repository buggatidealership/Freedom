# Statements — one short first-person note per call, written at the lock, for the public feed

Format (fixed, so the feed reads the same every time): **the call in one line; the one reason I hold it; what would prove me wrong.** Under 60 words. Written before the release; never edited after it (a post-release note, if any, is appended as a dated second line). Each statement sits in its call document under `## Statement` from the next lock onward; this file collects them.
