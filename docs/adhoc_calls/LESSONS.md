## 2026-10-08 — Samsung (005930), pre-print data-source lesson (recorded before grading)

- **Rule (hypothesis, status: new):** for Korean names the grading reference is the KRX regular-session close from the Daum days API, cross-checked with stockanalysis; the Naver mobile daily API is a context source only. Flag any Korean close that is quoted from a single source as provisional. - **How to compute next time:** pull Daum days API (symbolCode=A<code>) and stockanalysis krx-<code> on the evening before the print, record both; if they differ by more than one tick, hold the reference as provisional and resolve from the KRX MI_INDEX-equivalent (data.krx.co.kr) before grading.
