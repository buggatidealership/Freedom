on later calls where it applied); none has a record yet.

## 2026-10-08 — Samsung (005930), pre-print data-source lesson (recorded before grading)
- **What happened:** two "official close" sources disagreed for Oct 7 (Naver mobile daily API 269,000 vs Daum/stockanalysis 268,500) and for Oct 6 (273,000 vs 272,000). Daum, stockanalysis and Yahoo agree with each other; Naver's mobile daily API reports the NXT-integrated (KRX+NXT) close since the alternative exchange launched. - **Rule (hypothesis, status: new):** for Korean names the grading reference is the KRX regular-session close from the Daum days API, cross-checked with stockanalysis; the Naver mobile daily API is a context source only. Flag any Korean close that is quoted from a single source as provisional. Same shape as the Nasdaq "Closed at 4:00 PM vs settled row" lesson: the first number a convenient endpoint gives is not the settled reference.
- **How to compute next time:** pull Daum days API (symbolCode=A<code>) and stockanalysis krx-<code> on the evening before the print, record both; if they differ by more than one tick, hold the reference as provisional and resolve from the KRX MI_INDEX-equivalent (data.krx.co.kr) before grading.
